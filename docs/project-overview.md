# Project Overview

FLUID is an intelligent blood donation platform that connects verified hospitals with eligible blood donors in real time.

## Goals
- Help hospitals find suitable donors quickly
- Help donors manage availability and donation history
- Keep the platform secure, auditable, and scalable

## Primary Users
- Hospitals
- Donors
- Administrators

## Initial Scope
This scaffold includes only the platform foundation. Authentication, donor matching, donation workflows, notifications, and analytics are intentionally deferred.
